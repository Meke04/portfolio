# MekeDev - Portfólio

Portfólio pessoal desenvolvido com **Next.js, TypeScript e Tailwind CSS**, apresentando minhas habilidades, ferramentas, redes sociais e projetos.

## Como rodar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entre na pasta

```bash
cd nome-do-projeto
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

O projeto estará disponível em:

```text
http://localhost:3000
```
